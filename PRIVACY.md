# Privacy

Shorts Keyboard Controls does not collect, store on developer-controlled systems, sell, share, or transmit personal data.

## What the extension accesses

The extension runs on YouTube and YouTube Music pages so it can:

- identify the currently active video or Short;
- activate YouTube's existing Like and comments controls;
- change the current video's playback position;
- activate YouTube Music's existing Like control and change the current track's playback position;
- scroll the open Shorts comments panel.

This access happens locally in your browser. The extension does not read or transmit video history, comments, searches, account information, cookies, credentials, or other page content.

## Settings storage

The extension uses Chromium's `storage` permission only to save shortcut preferences, seek duration, scroll amount, and enabled/disabled settings. Chromium may sync those preferences through the browser account according to the browser provider's own sync settings and privacy policy.

The developer does not operate a server and does not receive those settings.

## Third parties

The extension contains no analytics, advertising, tracking pixels, remote code, or third-party libraries.

## Changes

If the extension's data practices change, this document and the release notes will be updated before the changed version is published.
